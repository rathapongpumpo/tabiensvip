# ทะเบียนสวยภูเก็ต

เว็บไซต์ขายทะเบียนรถสวยด้วย PHP และ SQLite มีหน้าร้าน ระบบค้นหา คำขอจอง และหลังบ้านสำหรับจัดการทะเบียน

## เริ่มใช้งาน

```powershell
php -S localhost:8000 router.php
```

เปิด `http://localhost:8000`

เส้นทางหลัก:

- ทะเบียนทั้งหมด: `http://localhost:8000/plates`
- รายละเอียดทะเบียน: `http://localhost:8000/plate/1`
- หลังบ้าน: `http://localhost:8000/admin`
- จัดการทะเบียน: `http://localhost:8000/admin/plates`

- ชื่อผู้ใช้: `admin`
- รหัสผ่าน: `admin123`

ควรเปลี่ยนรหัสผ่านทันทีจากเมนู “ตั้งค่าบัญชี”

ฐานข้อมูลจะถูกสร้างอัตโนมัติที่ `storage/tabian.sqlite` เมื่อเปิดเว็บไซต์ครั้งแรก
